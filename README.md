DESCRIPCION
El proyecto consiste en el desarrollo de una aplicación web para la clasificación de imágenes mediante Inteligencia Artificial y Machine Learning. Se utiliza el conjunto de datos CIFAR-10 para entrenar una red neuronal capaz de reconocer diferentes tipos de objetos.

El modelo puede identificar 10 categorías: avión, automóvil, pájaro, gato, ciervo, perro, rana, caballo, barco y camión.

El usuario puede subir una imagen o tomar una fotografía desde la cámara. La aplicación procesa la imagen, la analiza utilizando el modelo previamente entrenado y muestra como resultado el objeto identificado y el porcentaje de confianza de la predicción.

El modelo fue desarrollado y entrenado utilizando TensorFlow, mientras que la interfaz web fue creada con Streamlit. Finalmente, el código y el modelo se almacenan en GitHub y la aplicación se despliega en Streamlit Community Cloud, permitiendo acceder a ella mediante una URL pública.
